# 🧺 Ejemplos Básicos y Laboratorios de PHP

Este repositorio contiene una colección de ejemplos prácticos y ejercicios de laboratorio desarrollados en PHP para profundizar en los fundamentos del desarrollo web del lado del servidor.

## 📂 Contenido del Repositorio

* **Ejemplos Básicos:** Operaciones aritméticas básicas (suma, resta, multiplicación, división, potencia, módulo) y uso de la función `echo`.
* **Laboratorios Prácticos:** 
  * Cálculo de área y perímetro de figuras geométricas.
  * Funciones matemáticas como valor absoluto (`abs()`) y redondeo (`round()`).
  * Integración de PHP embebido en estructuras HTML.
  * Manipulación de variables y tipos de datos.

---

## 🛠️ Instrucciones de Ejecución

1. Asegúrate de tener **WampServer** (o un servidor local Apache/PHP) instalado y activo.
2. Clona o coloca esta carpeta dentro del directorio raíz del servidor (`C:\wamp64\www\Practicas`).
3. Abre tu navegador web e ingresa a una de las siguientes rutas:
   * `http://localhost/Practicas/`
   * `http://127.0.0.1/Practicas/`
